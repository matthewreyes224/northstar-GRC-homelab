# Step 01 — Hyper-V Foundation

## Objective

Create an isolated virtual platform that can support a realistic GRC and technology-risk lab without physical infrastructure.

## Current State

Hyper-V is the established virtualization platform for the project.

## GRC Relevance

The virtualization layer is part of the lab's infrastructure scope. Configuration decisions at this layer affect availability, segmentation, asset inventory, change management, and recovery planning.
